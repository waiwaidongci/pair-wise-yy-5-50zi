# 手工织锦纹样授权交付台

直接打开 `index.html` 使用。在原排版台（网格绘制、色线统计、撤销重做、本地保存、导出 JSON）基础上，扩展了纹样授权交付流程。

## 业务文件

| 文件 | 职责 |
| --- | --- |
| `snapshot.js` | 画布快照：送审时冻结当时的网格尺寸、逐格色线与色线板，生成结构哈希和色线用量，快照对象不可篡改 |
| `authorization.js` | 授权判定：项目编号+版本号在途唯一、审核人回避（不能与制版人相同）、审核通过签发含授权期限与适用范围的交付单、客户确认、画布改动自动失效、状态与剩余期限计算、客户/状态筛选 |
| `app.js` | 页面交互：画布绘制、方案信息、送审/审核/确认/详情弹窗、交付单卡片列表与筛选 |
| `index.html` | 页面结构与样式，按上述顺序引入三个脚本 |

## 使用流程

1. 填写项目编号、版本号、客户、制版人，在画布上完成纹样。
2. 点「冻结快照并送审」：同一项目编号+版本号若已有待审核或待客户确认的方案，会被拦截。
3. 审核人在交付单卡片点「审核」：审核人不能为空且不能与制版人相同；通过时须选择适用范围并设定授权起止日期，通过后生成交付单号。
4. 客户点「客户确认」后授权生效；卡片按当天日期显示「授权生效中 / 已到期」和剩余天数。
5. **客户确认前**再改动画布或色线（填色、新建网格、撤销重做等），同项目版本的待审/待确认单据自动标记为「已失效」并保留在历史中，只能用新快照重新送审；已确认的授权不受影响。
6. 列表支持按客户和状态筛选；「详情」可查看每版适用范围、授权期限、剩余期限、审核人与冻结快照的用色用量。

所有数据保存在浏览器 localStorage（`zfl31Deliveries` 为交付单，`zfl31Pattern`/`zfl31Meta` 为画布草稿与方案信息）。
